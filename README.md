## 🎨 Visual Aesthetic & Design System

The portfolio is designed with a high-contrast **"Monochrome Tech Scrapbook & Terminal Blueprint"** aesthetic (inspired by the award-winning grit.pictures design).

*   **Dotted Grid Background:** A clean, structural dotted mesh grid reflecting blueprint drafts.
*   **Rotated Sticker Labels:** Section headers and title items styled as physical labels held together by clear tape.
*   **Dual-Offset Shadowing:** Clean white component cards framed by black solid lines and offset background borders to create a stacked document look.
*   **Dynamic Cursor Physics:** Custom cursor outline and tracker using `mix-blend-mode: difference` to invert colors dynamically over light components, ensuring perfect readability.
*   **Micro-interactions:** Magnetic button hovers, scroll-triggered section slides, and viewport parallax movements.
